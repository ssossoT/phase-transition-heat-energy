중1 과학 학급실

입자 운동으로 이해하는 과학

실시간 시뮬레이터로 입자 간 거리, 진동, 결합 변화를 눈으로 직접 관찰하세요.

탐구 안내 및 단계별 학습 목표

3가지 탭을 눌러 주요 개념과 평가 기준을 살펴볼 수 있습니다.

고체 (Solid)
  • 입자들이 매우 빽빽하고 규칙적 배열
  • 제자리에서 미세한 진동 운동만 함
  • 모양과 부피가 일정함
액체 (Liquid)
  • 입자들이 고체보다 비교적 불규칙적
  • 서로 미끄러지듯 위치를 바꾸며 이동
  • 부피는 일정하나 모양은 용기에 따라 변함
기체 (Gas)
  • 입자 간 거리가 매우 멀고 매우 불규칙
  • 사방으로 매우 빠르게 날아다님
  • 모양과 부피가 모두 일정하지 않음

열에너지에 따른 상태 변화 용어

가열 (열에너지 흡수)

• 융해: 고체 → 액체

• 기화: 액체 → 기체

• 승화: 고체 → 기체

→ 입자 운동 활발해짐, 입자 사이 거리 멀어짐

냉각 (열에너지 방출)

• 응고: 액체 → 고체

• 액화: 기체 → 액체

• 승화: 기체 → 고체

→ 입자 운동 둔해짐, 입자 사이 거리 가까워짐
